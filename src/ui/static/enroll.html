CSR enrollment

Upload or paste a PKCS#10 CSR, declare the user, and download the signed certificate. Inspect either the CSR or the issued certificate (subject, key, and the Pontes privilege attribute).

Don't have a CSR yet? Generate a private key + CSR with the official ECB CertApp tool (runs in your browser, key never leaves it), or from the command line — see step 5 below or the full ENROLL-WITH-ECB-TOOLS.md guide.

5 · Create & install from the command line

      
Recommended for real keys — the private key never leaves your machine.

      
      
# 1) EC P-256 private key
openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out user.key

# 2) CSR with CN = username and the Pontes privilege extension
cat > csr.cnf <<'EOF'
[req]
distinguished_name = dn
req_extensions = exts
prompt = no
[dn]
CN = PFRBSUIFRPPXXX0001
[exts]
1.2.3.4.5.6.7.8.1 = ASN1:UTF8String:{"attrs":{"privilege":"2E","mspid":"BSUIFRPPXXX"}}
EOF
openssl req -new -key user.key -out user.csr -config csr.cnf

      
      
openssl pkcs12 -export \
  -inkey <your_private_key>.pem \
  -in    <your_cert>.pem \
  -name  "PFRBSUIFRPPXXX0001" \
  -out   PFRBSUIFRPPXXX0001.p12

      
      
security import PFRBSUIFRPPXXX0001.p12 -k ~/Library/Keychains/login.keychain-db
# verify:
security find-identity -v ~/Library/Keychains/login.keychain-db | grep PFRBSUIFRPPXXX0001

      
⚠️ Known macOS bug (observed on macOS 26.6.2): importing a PKCS#12 with an
        EC (P-256) private key — the type Pontes requires — can fail in Keychain Access with
        OSStatus -26276 or similar, regardless of the PKCS#12 cipher used (RSA keys are
        unaffected). This is a bug in Apple's own PKCS#12 importer, not the certificate/key. If you hit
        this, use Firefox (below) or skip Keychain entirely (CLI mTLS, further below).

      
      
Settings → Privacy & Security → Certificates → View Certificates
  → Your Certificates → Import… → select the .p12

      
      
# fetch the mock's CA once (one-time -k), then verify against it:
curl -sk https://localhost:3001/ca.pem -o mock-ca.pem
curl --cert <your_cert>.pem --key <your_private_key>.pem \
     --cacert mock-ca.pem https://localhost:3001/check/mtls
